## Body Change Scope / Lossless Preservation

The D25 original recovery is separate historical evidence. Its original overall
result failed; this successor procedure uses reviewed recorded argument order,
explicit paths and retained inputs without substituting the newer old helper.
FEX compiles three selected units, Wine three and graphics five. Declared objects,
archives, generated configuration and compiler/SDK bytes supply unchanged lower
layers. This is not a complete clean upstream rebuild.

Actual dependency and linker observations closed missing inputs. Graphics retains
the lexical clang++ invocation and libc++ dependency; binary Symbols-table bytes
in native link maps do not weaken strict Object-files table validation. All
failed attempts retain their errors, commands and evidence. Shared headers keep
single owners; original MIT transport terms and provenance are preserved.
